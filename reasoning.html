    Methods, limitations and source files

    Mean counting error = mean of |prediction − supplied count| ÷ supplied count × 100. Every scored image has equal weight. Zero or conflicting supplied counts cannot be used for percentage deviation. Predictions are never rounded before scoring.

    Cost is the saved API-reported USD charge, including billed reasoning and known failed-call charges. Unknown charges stay unknown. Cost points require complete predictions and known charges. Confidence points require valid counts and confidence for the same full image set. Partial runs remain in the table and may have coverage curves ending below 100%.

    Thin cost connectors and low-to-high conclusions require matching recorded settings within a model, apart from effort. Missing intermediate levels break the connector. Different token caps, provider endpoints and sampling settings across models limit causal comparisons. Settings are exposed in the table and source files.

    Confidence remains P(exact count). Comparing mean confidence with mean numerical error is not formal probability calibration. Coverage curves use confidence-ranked subsets within each model/effort configuration. Pooled cutoff summaries repeat the same images across configurations; they are not independent new image samples. With this small, selected pilot, useful cutoffs need further evaluation.

    Predictions and confidence: eval4/ only; smoke tests and other evaluation folders are excluded. Supplied counts: existing scoring metadata, joined by group and image. These counts have not been independently audited here. Read the runner. No model API requests are made by this page.

    Dataset: FSC-147 / Learning To Count Everything, Viresh Ranjan, Udbhav Sharma, Thu Nguyen and Minh Hoai (CVPR 2021). Source images · Paper · Recorded download URL. This page covers selected Group 1 images, not the full FSC-147 benchmark. DL models are not part of these charts.
